# 🤖 AI News Automation Workflow

An automated AI workflow built with n8n that collects the latest AI news every day, sends a formatted email newsletter, and stores all news data inside Google Sheets automatically.


# 🚀 Features

* 📰 Daily AI news aggregation
* 📧 Automated email delivery every morning at 10:00 AM
* 📊 Automatic Google Sheets logging
* 📅 Date-based news tracking
* ⚡ Fully automated workflow
* 🔄 Scheduled daily execution


# 🛠️ Tech Stack

* n8n Automation
* Google Sheets API
* Email Automation
* AI News Sources / RSS Feeds
* Scheduled Cron Trigger

# ⚙️ Workflow Overview

The automation performs the following steps every day:

1. Trigger starts automatically at 10:00 AM
2. Latest AI news articles are collected
3. News content is formatted into an email newsletter
4. Email is sent automatically
5. All articles are logged into Google Sheets with today's date
